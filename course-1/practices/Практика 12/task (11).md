# Практика №12
Уровень 1
Задание 1. Животные
1. Создайте базовый класс Animal, в котором есть:
- свойство Name;
- метод Eat(), который выводит:
 "Животное ест.".
2. Создайте два дочерних класса:
- Dog — добавь метод Bark(), который выводит "Собака лает.";
- Cat — добавь метод Meow(), который выводит "Кошка мяукает.".

Задание 2. Говорящие животные
1. В базовом классе Animal добавьте виртуальный метод:
```
public virtual void Speak()
{
    Console.WriteLine("Животное издаёт звук");
}
```
2. В классах Dog и Cat переопределите этот метод (override):
- Dog выводит: "Собака говорит: Гав-гав!";
- Cat выводит: "Кошка говорит: Мяу!"

Задание 3. Расширение поведения base
1. Добавьте в базовый класс Animal метод public virtual void Move(), который выводит "Животное двигается.".
2. В классе Dog переопределите метод Move(), чтобы он сначала вызывал метод родителя через base.Move(), а потом выводил: "Собака бежит по дороге.".

Уровень 2
Задание 4. Конструктор с base
1. В классе Animal добавьте конструктор:
```
public Animal(string name)
{
    Name = name;
    Console.WriteLine($"Создано животное: {Name}");
}
```

2. В классе Cat добавьте конструктор:
```
public Cat(string name) : base(name)
{
    Console.WriteLine($"Создана кошка по имени {Name}");
}
```
Задание 5. Многоуровневое наследование
1. Создайте три класса:
- Transport — метод Drive() → "Транспорт движется";
- Car (наследуется от Transport) → переопредели метод Drive() → "Машина едет по дороге";
- ElectricCar (наследуется от Car) → переопредели метод Drive() → "Электромобиль тихо едет на батарее".
