# Практика №17
Уровень 1
Задание 1. Из массива чисел оставить положительные чётные, возвести в квадрат, посчитать сумму, количество и среднее

Задание 2. Из списка слов взять те, что начинаются на «А/а», привести к верхнему регистру, отсортировать по длине, убрать повторы.

Задание 3. Из списка учеников выбрать тех, у кого оценка ≥ 4, отсортировать по имени и вывести только имена; попробовать использование Any/All.

Задание 4. Сгруппировать даты по месяцу, для каждой группы вывести количество, минимальную и максимальную дату.

Задание 5. Из словаря Имя, Баллы сделать список строк «Имя — Баллы», отсортированный по баллам по убыванию.

Задание 6. По товарам {Name,Category,Price,Stock} сгруппировать по категории и вывести Count, Average(Price), Sum(Stock) и самый дорогой товар.

Уровень 2
Задание 7. Даны коллекции: Student(Name, Club) и ClubInfo(Club, Room). 
1. Выполнить join по названию клуба и вывести «Имя — Клуб (Кабинет)».​
2. Выполнить левое соединение: вывести всех студентов, даже если их клуб не найден, подставляя кабинет «—».

Задание 8. Для двух списков строк получить Union/Intersect/Except и проверить равенство упорядоченных последовательностей через SequenceEqual.
