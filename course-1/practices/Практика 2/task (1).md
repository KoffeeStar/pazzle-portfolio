# Практика №2
Уровень 1
Задание 1: Создание и инициализация проекта
1. Создайте папку git-practice на рабочем столе через Проводник.
2. Откройте эту папку в терминале (например, через ПКМ Открыть в терминале).
3. Выполните команду:
```
git init
```

Задание 2: Создание файла и добавление в индекс
1. Создайте в папке git-practice новый текстовый файл notes.txt.
2. Напишите в нём что-нибудь (например, «Мои заметки по Git»).
3. Выполните команды:
```
git status
git add notes.txt
git status
```

Задание 3: Создание коммита
1. Сделайте первый коммит с понятным сообщением:
```
git commit -m "feat: добавлен файл для ведения заметок по Git"
```

Задание 4: Изменение файла и новый коммит
1. Откройте notes.txt и добавьте новую строку (например: «Изучаю git add и git commit»).
2. В терминале выполните:
```
git status
git add notes.txt
git commit -m "docs: добавлены заметки о командах git add и git commit"
```

Задание 5: Проверка истории коммитов
1. Посмотрите все сделанные коммиты:
```
git log --oneline
```

Уровень 2
Задание 6: Привязка к удаленному репозиторию
1. Зайдите на GitHub и создайте новый репозиторий git-practice.
2. В терминале в папке проекта привяжите локальный репозиторий к GitHub.
```
git remote add origin git@github.com:ваш_профиль/git-practice.git
```

Задание 7: Отправка изменений на Github
1. Отправьте свои коммиты:
Для первой отправки
```
git push -u origin main
```
Для последующих:
```
git push
```
