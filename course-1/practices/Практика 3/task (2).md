# Практика №3
Уровень 1
Задание 1: Создание репозитория с ветками
1. Создайте папку git-branches на рабочем столе.
2. Откройте её в терминале и выполните инициализацию:
```
git init
```
3. Создайте файл story.txt. Напишите в нем текст: Это начало моей истории.
4. Добавьте файл и сделайте первый коммит:
```
git add story.txt
git commit -m "feat: добавлен файл story.txt с началом истории"
```
5. Создайте новую ветку feature и переключитесь в неё:
```
git checkout -b feature
```

Задание 2: Изменение файла в ветке feature
1. Откройте story.txt и добавьте строку: Ветка feature добавляет новую главу.
2. Сохраните файл.
3. Сделайте коммит:
```
git add story.txt
git commit -m "feat: добавлена глава из ветки feature"
```

Задание 3: Изменение файла в ветке main
1. Переключитесь обратно на ветку main:
```
git checkout main
```
2. Откройте story.txt и добавьте строку: Ветка main продолжает свою версию истории.
3. Сделайте коммит:
```
git add story.txt
git commit -m "feat: добавлена глава из ветки main"
```

Уровень 2
Задание 4. Вызов merge-конфликта
1. Находясь в ветке main, попробуйте слить изменения из feature:
```
git merge feature
```
2. Git сообщит о конфликте и пометит файл story.txt.

Задание 5. Разрешение конфликта
1. Откройте story.txt. Вы увидите примерно такой текст:
```
Это начало моей истории.
<<<<<<< HEAD
Ветка main продолжает свою версию истории.
=======
Ветка feature добавляет новую главу.
>>>>>>> feature
```
2. Исправьте файл так, чтобы история выглядела логично. Например:
```
Это начало моей истории.
Ветка main продолжает свою версию истории.
Ветка feature добавляет новую главу.
```
3. Удалите все строки <<<<<<<, =======, >>>>>>>.
4. Добавьте исправленный файл в индекс:
```
git add story.txt
```
5. Завершите merge:
```
git commit
```
