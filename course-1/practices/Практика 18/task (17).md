# Практика №18
Уровень 1
1. Проверка компонента ASP.NET и веб-разработка
- Перейдите в Visual Studio Installer для того, чтобы проверить установлен ли компонент.
- Установите в случае отсутствия.
2. Создание бота
Пока устанавливается компонент выполните шаги для создания ТГ бота: 
- Переходим по ссылке, попадаем в диалог с BotFather и жмем "Запустить". BotFather - это официальный бот Telegram, через которого проходит регистрация и настройка ваших ботов.
- От вашего лица должна отправиться команда /start , на которую бот ответит большим списком команд с описаниями. Подробно изучить каждую Вы можете самостоятельно.
- Используем команду /newbot. На этом шаге нужно отправить боту имя Вашего будущего бота. Например, пусть это будет Chat.
- Далее нас попросят ввести username бота, учтите, что он должен быть написан строго на латинице, а также содержать bot или _bot в конце. Username - это уникальный идентификатор аккаунта (вашего или бота), по которому люди могут найти аккаунт в поиске. В случае, если username уже занят, вас попросят использовать другой.
- После всех выполнений действий, BotFather присылает нам небольшое сообщение, в котором говорится об успешном создании бота. Из этого сообщения нам нужен token (уникальный ключ), с помощью которого мы будем авторизировать нашего бота в дальнейшем, он имеет примерно такой вид: 13523457:AFAgd_SDFG6sd7f6asdf67asdf78. Учтите, что абсолютно никому нельзя присылать этот token! Это ваш секретный ключ для доступа к боту. Сохраните его.
3. Создание проекта
После установки компонента
- Вариант 1: Visual Studio
 - Создайте проект: ASP.NET Core Web API.
 - Оставьте включенным Swagger (Enable OpenAPI support).
 - Если используется .net > 8, то для запуска Swagger необходимо:
  - установить nuget-пакет Swashbuckle.AspNetCore
  - в Program.cs добавить:
     - builder.Services.AddSwaggerGen();
     - app.UseSwagger();
     - app.UseSwaggerUI();
- Вариант 2: VS Code / CLI
```
dotnet new webapi -o ChatBot
cd ChatBot
dotnet run
```

Уровень 2
4. Запуск Swagger
    1. Запустите проект (F5 в Visual Studio или dotnet run в терминале).
    2. Посмотрите в консоль, на каком порту запустился API (например, https://localhost:7162).
    3. Откройте браузер и перейдите по адресу:
     - https://localhost:7162/swagger
    4. Вы увидите страницу Swagger UI со списком методов. В стандартном шаблоне есть:
     - GET /weatherforecast
    5. Нажмите на GET /weatherforecast → Try it out → Execute.
