# Практика №5
Уровень 1
Задание 1: Установка .NET SD
1. Перейдите на сайт https://dotnet.microsoft.com/download.
2. Скачайте и установите .NET SDK.
3. Проверьте установку (введите команду в терминал):
```
dotnet --version
```

Задание 2: Установка Visual Studio
1. Перейдите на сайт https://visualstudio.microsoft.com/ru/vs/community/.
2. Скачайте и установите Visual Studio Community.
3. Запустите установщик.
4. В списке Workloads выберите: .NET desktop development.

Уровень 2
Задание 3: Создание проекта
1. Откройте Visual Studio.
2. Нажмите “Create a new project”
3. Выберите Console App (C#).
4. Введите имя проекта → Create.

Задание 4: Первый запуск
1. В открывшемся редакторе появится код программы.
2. Нажмите зеленую кнопку (рядом с ней будет название проекта).
3. В консоли появится:
```
Hello, World!
```
