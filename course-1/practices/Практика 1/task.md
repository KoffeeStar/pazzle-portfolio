# Практика №1
Уровень 1
Задание 1: Установка Git
1. Скачиваем Git: https://git-scm.com
2. Устанавливаем Git (стандартная установка)
3. Настраиваем имя и email:
```
git config --global user.name "Ваше Имя"
git config --global user.email "ваш.email@example.com"
```

Задание 2: Регистрация на Github
1. Перейдите по ссылке GitHub и пройдите регистрацию
