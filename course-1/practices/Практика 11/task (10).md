# Практика №11
Уровень 1
Задание 1. Перегрузка конструкторов
1. Создайте класс Book, который может быть создан разными способами:
- без параметров (значения по умолчанию);
- только с названием книги;
- с названием и автором;
- с названием, автором и количеством страниц.
Добавьте метод PrintInfo(), который выводит информацию о книге в консоль.

Задание 2. Использование this для вызова другого конструктора
1. Создайте класс Car, в котором:
- есть свойства Brand, Model, Speed;
- реализованы три конструктора:
 - без параметров (значения по умолчанию);
 - с параметром brand;
 - с параметрами brand и model.
Используйте this(...), чтобы один конструктор вызывал другой.

Задание 3. Класс Person
1. Создайте класс Person, который хранит имя и возраст.
- Поля должны быть приватными.
- Доступ к ним осуществляется через свойства.
- Возраст не может быть отрицательным.
- Имя нельзя задать пустым.

Уровень 2
Задание 4. Класс BankAccount
1. Создайте класс BankAccount:
- приватное поле balance;
- методы:
 - Deposit(decimal amount) — пополнить счёт;
 - Withdraw(decimal amount) — снять деньги (если хватает средств);
 - ShowBalance() — показать текущий баланс.
Проверьте, чтобы нельзя было снять больше, чем есть на счёте.

Задание 5. Класс Thermometer
1. Создайте класс Thermometer:
- приватное поле temperatureCelsius;
- свойство TemperatureCelsius (не ниже -273);
- добавьте свойство TemperatureFahrenheit, которое вычисляется по формуле (C * 9 / 5) + 32.
