# Практика №15
Уровень 1
Задание 1
1. Создайте файл notes.txt, запишите 3 строки.
2. Запишите еще одну строку.
3. Прочитайте и выведите содержимое.
4. Удалите файл, если подтверждение пользователя “y”.

Задание 2
1. Создайте каталог data, внутри — несколько .txt файлов.
2. Выведите список всех .txt с размерами.

Задание 3. Резервная копия файла
1. Попросите пользователя ввести путь к файлу.
2. Скопируйте его в тот же каталог с суффиксом .bak, если файл существует.

Уровень 2
Задание 4. Логи с датой и очистка старых логов
1. Записывайте в logs/yyyy-MM-dd.log строку с текущим временем и сообщением.
2. Удаляйте логи старше N дней.
