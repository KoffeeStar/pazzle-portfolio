# Домашнее задание №7
Уровень 1
Задание 1
1. Создайте интерфейс IMessageSender:
- метод Send(string message).
2. Создайте классы, реализующие этот интерфейс:
- EmailSender — в методе Send выводит: "Отправка email: {message}";
- SmsSender — в методе Send выводит: "Отправка sms: {message}".
- В методе Main создайте массив интерфейсов и заполните его объектами разных классов. Пройдитесь по массиву в цикле и вызовите метод Send.

Уровень 2
Задание 2
1. Создайте класс NotificationHub. Этот класс должен управлять коллекциями отправителей и статистикой:
- Внутри класса создайте поле List<IMessageSender> для хранения всех подключенных отправителей.
- Создайте поле Dictionary<string, int> для подсчета количества сообщений, отправленных через каждый тип канала (ключ — название класса, значение — количество).
- Реализуйте метод Register(IMessageSender sender) — добавляет отправителя в список.
- Реализуйте метод SendAll(string message) — отправляет сообщение через все каналы из списка и обновляет статистику в словаре.
- Реализуйте метод GetStats() — возвращает словарь со статистикой.
